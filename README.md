## 📊 My Development Philosophy

I believe that understanding **why something works** is more important than simply making it work.

My learning process is:

```text
Learn the concept
      ↓
Implement it from scratch
      ↓
Visualize it
      ↓
Test it
      ↓
Break it
      ↓
Debug it
      ↓
Improve the implementation
```

I want my projects to demonstrate not only the final result, but also the **reasoning and engineering behind it**.
